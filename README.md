# אתר בדיקת סילבוסים

מעלים לאתר סילבוס אחד או יותר (Word או PDF), וכל אחד נבדק מול 15 רכיבי החובה של התבנית. על כל סילבוס מקבלים אישור, או טבלה של החוסרים והערות לתיקון. כשמעלים כמה סילבוסים יחד, מופיעה גם טבלת סיכום. אפשר להדפיס את התוצאות או לשמור אותן כ-PDF.

## מה צריך
1. **מפתח API של Anthropic:** נכנסים ל-console.anthropic.com, יוצרים מפתח תחת API Keys ומוסיפים יתרה. בדיקה של סילבוס אחד עולה בסביבות כמה סנטים.
2. **חשבון GitHub** וגם **חשבון Vercel**. שניהם חינמיים, ואפשר להירשם ל-Vercel עם חשבון ה-GitHub.

## פרסום (כ-10 דקות)
1. ב-GitHub יוצרים מאגר חדש (New repository), למשל בשם `syllabus-checker`, ומגדירים אותו כ-Private.
2. בעמוד המאגר לוחצים **uploading an existing file** וגוררים לשם את כל התיקייה הזו: `api`, `lib`, `public`, `package.json`, `README.md` ו-`dev-server.mjs`. לוחצים Commit.
3. ב-vercel.com לוחצים **Add New > Project**, בוחרים את המאגר ולוחצים Import.
4. לפני שלוחצים Deploy, פותחים את **Environment Variables** ומוסיפים:
   - `ANTHROPIC_API_KEY` עם המפתח שיצרתם.
   - `ACCESS_CODE` עם סיסמה לבחירתכם, למשל `syl2026`. בלי הסיסמה הזו, כל מי שימצא את הכתובת יוכל להשתמש באתר על חשבונכם.
5. לוחצים **Deploy**. אחרי כדקה מתקבלת כתובת כמו `syllabus-checker.vercel.app`, ואותה (יחד עם הסיסמה) שולחים למי שצריך.

## שינוי כללי הבדיקה
הכללים כתובים בקובץ `lib/rules.js` בעברית. עורכים אותו ישירות ב-GitHub, שומרים (Commit), ו-Vercel מעדכן את האתר מעצמו תוך דקה.

## הרצה מקומית (לא חובה)
```
npm install
ANTHROPIC_API_KEY=... node dev-server.mjs
```
ואז פותחים את http://localhost:3000.

## כדאי לדעת
- גודל קובץ מקסימלי הוא כ-3MB. סילבוס רגיל קטן בהרבה.
- קובץ Word ישן (doc) לא נתמך. שומרים אותו מחדש כ-docx או כ-PDF.
- הקבצים לא נשמרים בשום מקום. הם נשלחים ל-Claude לבדיקה, ומה שנשאר אחר כך הוא רק התוצאה שמוצגת בדפדפן.
